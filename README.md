# 🐳 MERN Docker App

> A full-stack MERN application containerized with **Docker and Docker Compose** for learning containerized development.

## 📌 About

This project was built to understand how Docker works with a real MERN application. I containerized the **React frontend, Node.js/Express backend, MongoDB, and Mongo Express** and connected them using Docker Compose.

### 🧠 What I Learned

* 🐳 Docker images & containers
* 🧩 Docker Compose
* 🌐 Container networking
* 🔌 Port mapping
* 🔄 Bind mounts & volumes
* 🔐 Environment variables
* 📦 Docker Hub
* 🚀 Running a complete MERN stack with Docker

**Tech Stack:** React • Node.js • Express • MongoDB • Docker • Docker Compose
